Number Patterns

A number pattern is a sequence that follows a rule. The sequence can increase, decrease, multiply, divide, or follow a special pattern.

Example
6, 12, 18, 24, 30
Rule: Add 6 each time

Patterns in Tables

A table helps us organize a pattern. The first row shows the input values, and the second row shows the output values. We compare the values to find the rule.

Example Table
x12345
y3691215
Rule: Multiply x by 3 to get y
